# Pinocchio (PNH)

A CPU mineable Scrypt cryptocurrency. Mine with your computer. Fair launch. No ICO. No presale.

## Mining

Mine using cpuminer with Scrypt algorithm:

./minerd -a scrypt -o ... -u user -p pass --coinbase-addr=YOUR_PNH_ADDRESS -t 4
